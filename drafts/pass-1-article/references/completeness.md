# 检查调研能否支持其结论

完整是相对于用户要解决的问题和约定的主张而言。先界定本次审查范围，读取用户要求、已有研究、关键来源、分析与验证记录；记明只检查文字、已核查材料、或已重跑了什么。材料中拟执行的工作按计划看待。

新审查任务按所需分支回答前置问题并改写审查请求。审查研究方法框架时，检查它能指导哪些任务，不虚构它已经在这些领域证明有效。

## 逐项检查关键主张

按实际任务选用下列检查；不适用时说明理由。

| 检查项 | 要核对什么 | 常见实质缺口 |
|---|---|---|
| 目标与范围 | 需要回答的问题、用途、对象和边界是否明确。 | 研究量增加却没有解决用户判断。 |
| 目标重审与约束 | altitude 的目标解释是否有依据，明确约束和交付物是否保留，冲突是否交由有决定权的人处理。 | 把推断当用户目标；删掉明确方式；自行设多目标权重。 |
| 路径与比较 | 原方案及可行替代项是否按同一结果与约束比较，成本和迁移是否完整。 | 默认新方案更优；违反约束的方案进入推荐；只优化代理指标。 |
| 跨领域迁移 | range 是否有行为描述、关键障碍、源与目标机制对应、具体方法和迁移条件。 | 角色扮演代替执行；表面相似推出适用；领域数量代替收益。 |
| 专业补充 | 是否补足影响判断的专业工作，理由是否具体。 | 以专家姿态或工具名代替工作设计。 |
| 主张与方法 | 方法能否支持事实、因果、预测等对应结论。 | 前后变化推因果；同批样本推泛化；演示推现场可用。 |
| 检索与取舍 | 实际渠道、查询、限制和纳入排除是否可追查。 | 只搜到赞同材料；重要来源未覆盖却宣称穷尽。 |
| 原始材料与形成过程 | 来源、版本、采集、筛选、抽取和加工是否清楚。 | 把原始程度或官方身份当作可靠性。 |
| 独立性与冲突 | 同源报告是否关联，重要差异是否对齐口径并处理。 | 转载多数当证据；异质结果直接平均。 |
| 分析假设与敏感性 | 指标、分母、比较、缺失、关键假设的变化是否影响答案。 | 隐去基线；无精度依据；结论依赖未说明的处理选择。 |
| 反证与否定判断 | 是否检验竞争解释，搜寻或测量是否有检测能力。 | 没搜到推不存在；未显著推无效果。 |
| 外部验证 | 标准是否提前说明，实际独立程度与适用范围是否准确。 | 重算、模型赞同或验证计划被写成独立验证完成。 |
| 变化与执行状态 | 当前版本、时间与环境是否适合决策，实际检查是否有记录。 | 旧快照证明当前能力；未执行步骤被写为完成。 |
| 收尾与可复用性 | 关键未知是否处理、剩余未知是否影响判断、记录能否继续使用。 | 用篇幅或资料数量代替完成依据；规则无法执行。 |
| 递归修订 | 每轮是否有具体发现、修订理由和复查，探索与新证据验证是否分开。 | 按轮数改写；在同一案例上反复调整后宣称已证明泛化。 |

## 根据影响安排修补

每项实际缺口说明：所在主张或规则、现有材料、缺什么、怎样影响结论、最小修补动作、怎样确认修补完成。证据不足的地方保留不足，避免为填写清单制造缺陷。

优先修补会翻转核心答案、使推断无效或混淆执行状态的缺口。其次处理限制适用范围和可靠性的缺口。表达和排版根据对读者理解的影响安排，不用综合分数掩盖关键问题。

用户只请求审查时交付审查结果。用户授权修补时做能完成的修补，原事实和范围保留；需要新数据、访问或长期观测的部分单列待完成条件。

## 交付审查结论

先说明现有内容是否足以承担其目标，再给最重要缺口、实际修补结果和剩余限制。审查表可用下列格式，条数依真实问题决定。

| 问题或主张 | 现有依据与缺口 | 对结论的影响 | 修补动作及实际状态 |
|---|---|---|---|
| 实际位置和判断 | 实际核对结果 | 核心推断、适用性或表达影响 | 已完成检查，或待满足条件 |

完成依据：所有影响核心答案的主张已核对到明确状态；读者知道哪些已经检查、哪些仍需证据。静态规范通过、文字扫描通过和案例走查各自说明范围，不能据此宣称 Skill 在所有实际任务中有效。
