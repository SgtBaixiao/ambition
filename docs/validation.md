## 冻结、包与原方法保留

第一遍和第二遍各冻结十个方法及元数据文件，哈希见[第一遍清单](../evidence/pass-1-manifest.json)和[第二遍清单](../evidence/pass-2-manifest.json)。公开分发时另加入 MIT `LICENSE`，不改所测十个文件。最终包为十一文件，两遍 ZIP 也包含许可证；历史入口在仓库保存为 `SKILL.md.snapshot`，打包还原为 `SKILL.md`，避免安装器发现同名旧版本。

当前版本与两遍方法版本均通过 skill-creator 的格式验证器。最终二十处本地引用、两遍历史引用、界面元数据和包完整性核对通过；最终包与第二遍方法哈希一致。ZIP 各文件解压后的哈希与源文件、安装副本相同。

旧 depth 主体与旧发布包逐字比较，仅有移入参考目录所需的链接调整。altitude、depth、方法选择、证据处理及迭代主体与本轮基线一致；路由、完备性条目、来源和界面说明为 range 增补。

本次核对十二份旧方法 HTML 快照、四份 altitude 原始文件，以及 Felix 原网页和三篇类比论文的四份原始文件哈希。快照只在本地保存；公开资料保留来源定位与哈希，未分发第三方全文。

更新后的 ambition 已安装到 Codex 技能目录；只归档与基线哈希相同的旧副本，源文件、安装与 ZIP 的十一文件一致。实际检查摘要保存在[产物检查记录](../evidence/artifact-check.json)中。仓库、Release、远程安装和目录站收录作为不同结果单独核对。

## 证据能支持到哪里

九个请求检查所测任务下的行为，来源核查支持设计要素，格式与哈希检查支持包一致性。没有有无 Skill 的随机对照、全领域代表性样本、真实迁移试点或用户现场验收；不能据此宣称效率提升幅度、跨领域普遍收益或宿主自动触发已经成立。

S2 和 S4 的源方法文档没有进入案例输入，执行者据此保留探索状态和进入条件。这符合有限材料下的计划边界，也意味着它们没有完成源领域成熟性验证。后续实际任务仍须取得所选领域的原材料和效果证据。

中文正文的实际扫描、事实核对与必要豁免在[写作检查记录](writing-check.md)中保存；模型原输出保持原样，作为行为材料。
