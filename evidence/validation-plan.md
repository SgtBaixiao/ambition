# range 两遍打磨的检查条件

记录日期：2026 年 11 月 24 日。本次按用户要求保留两遍完整 Skill 产物：第一遍依据 Felix 文章细化 range；第二遍结合用户五问、方法来源核查与实际检查发现扩展。每遍冻结文件哈希，行为执行者不取得本表和预期答案。

## 第一遍检查

| 案例 | 在读取输出前确定的关键条件 |
|---|---|
| R1，季度评审 | PPT、20 分钟、现有材料及资源要求保留；跨领域方法优先处理口径冲突，不以记者、分析师等角色名称替代步骤；提出可检查的试验。 |
| R2，入职指南 | 文档保留，方法针对实际错误下的操作能力；每日 30 分钟限制保留；讲解或背诵不能单独证明现场能力。 |
| R3，3D 首页提议 | 不因文章示例预设 Blender 适合；旧手机、慢网、互动与零预算保留；工具和成熟程度没有核查时准确标明，不安装或改页面。 |

检查行为、方法及证据状态，避免按固定用词评分。目标或约束被替换、表面类比充当适用证明、工具能力被编造或计划越界执行属于关键失败。真实数据或现场结果缺失时，合理的条件性计划可以通过。

## 第二遍检查

新材料检查结构类比失配、原领域方法可保留、方法组合与可归因性、普通任务触发边界及已存 depth／altitude 行为。执行前记录具体请求和判断条件，冻结第二遍；评测材料与第一遍见过的案例分开。

| 新案例 | 事前关键检查 |
|---|---|
| S1，五分钟核对 | 可以保留原清单，不为了跨度增加流程或工具；原格式及计划边界保留。 |
| S2，异步系统 | M/M/1 假设与成批到达、长尾、多 worker 不匹配；不能从均值宣称 p95 达标；难题、失败和重试不能消失于统计。 |
| S3，组合改善 | 两个季度、多项同时变化、一次观测不足以识别新闻叙事贡献；工作转移和决策结果仍需检查。 |
| S4，创作工作坊 | 个人完成歌曲、审美与试错、20 分钟和不增文档均保留；具体方法针对熟悉段落重复，效果保持待验证。 |
| S5，depth 回归 | 采集关闭与日期混杂限制结论；只审查及规划。 |
| S6，普通实现边界 | 简短确认既定文案，不启动完整流程。 |

两遍检查均是构造任务下的模型行为观察。没有有无 Skill 的随机对照、真实用户效果或全领域样本，不能证明方法提高多少。方法来源支持规则要素，案例输出只支持所测行为。
